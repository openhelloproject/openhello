# Security policy

OpenHello is authentication software, so please report vulnerabilities
privately: email **penealfeleke17pro@gmail.com** with "OpenHello security"
in the subject, or use GitHub's private vulnerability reporting on this
repository. Please include steps to reproduce and the affected version. You
can expect an acknowledgement within a few days.

Please don't open public issues for vulnerabilities until a fix is available.

What OpenHello does and doesn't protect against is described in
[docs/SECURITY.md](docs/SECURITY.md).
